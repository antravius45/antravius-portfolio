# Antravius Thomas Personal Portfolio

This portfolio contains:
- Home page
- Projects/Work page
- About/Contact page
- Responsive CSS for mobile and desktop
- JavaScript DOM interactions
- Accessible contact-form validation
- Clean HTML/CSS/JS folder structure

## Folder structure

```text
antravius-portfolio/
├── index.html
├── projects.html
├── about.html
├── css/
│   └── style.css
└── js/
    └── script.js
```

## GitHub Pages

1. Create a new GitHub repository.
2. Upload all files and folders from this project.
3. Make sure `index.html` is in the repository root.
4. Open the repository's **Settings > Pages**.
5. Under the build/deployment section, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.
7. Wait for GitHub Pages to publish the site.
8. Copy the live Pages URL into your assignment submission.

## Before submitting

Test the website at approximately 320px and 1200px widths using browser DevTools.
Run the published pages through WAVE and fix any errors it reports.
Check keyboard navigation with Tab, Enter, and Space.
